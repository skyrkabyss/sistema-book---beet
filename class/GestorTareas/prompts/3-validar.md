# Validar implementación SDD

Lee los archivos:
- AGENTS.md
- specs/tareas.md

Revisa la implementación existente.

## Actividades

1. Comparar el código con RF01-RF04.
2. Comprobar los criterios CA01-CA08.
3. Verificar las validaciones del modelo.
4. Verificar la persistencia mediante SQLite.
5. Revisar las operaciones HTTP.
6. Ejecutar dotnet build.
7. Ejecutar las pruebas automatizadas disponibles.

## Restricciones

- No modificar archivos.
- No borrar la base de datos.
- No crear funcionalidades nuevas.
- No reportar como aprobadas pruebas no ejecutadas.

## Entregable

Genera un informe en la respuesta con:

- Criterio de aceptación.
- Estado: Cumple, No cumple o No verificado.
- Evidencia encontrada.
- Cambios necesarios.

Distingue resultados de análisis estático, compilación y pruebas ejecutadas.
